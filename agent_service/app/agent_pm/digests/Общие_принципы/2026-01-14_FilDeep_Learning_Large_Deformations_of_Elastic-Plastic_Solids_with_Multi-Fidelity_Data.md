# Описание:
## 1. Цель:
Предложить новый метод глубокого обучения для моделирования больших упругопластических деформаций твердых тел с использованием многоуровневых данных (multi-fidelity data).

## 2. Проблема:
Традиционные методы численного моделирования не способны эффективно обрабатывать большие деформации материалов, особенно в условиях сложной комбинации упругих и пластических свойств. Многоуровневые данные предлагают компромисс между точностью и вычислительной эффективностью, однако требуют сложных подходов для эффективного интегрирования в модели машинного обучения.

## 3. Задачи:
Разработать архитектуру глубокой нейронной сети, способную корректно предсказывать большие деформации твердых тел, используя разнородные источники данных различной точности.

## 4. Подход — суть алгоритма/метода:
Предлагается **архитектура** глубокой нейронной сети (глубокое обучение), названная FilDeep, специально разработанная для моделирования крупных упругопластических деформаций. **Архитектура** включает:
- Двухуровневую структуру слоев, состоящую из:
- Fine Layer (тонкий слой): предназначен для обработки высокодетализированных и высокоточных данных
- Coarse Layer (грубый слой): обрабатывает менее детализированные и менее точные данные
- Гибридный механизм объединения различных уровней данных, основанный на адаптации глубины слоев для оптимальной интеграции разнородных данных.

## 5. Как реализуется подход:
**Архитектура** сети реализована следующим образом:
- Входной слой принимает данные нескольких уровней точности.
- Два слоя выполняют различные функции обработки: тонкий слой улучшает локальные детали и тонкую информацию, грубый слой повышает глобальную стабильность и снижает вычислительную сложность.
- Данные передаются через слой объединения, который адаптирует глубину слоя и объединяет информацию разных уровней.
- Используется многослойная перцептивная сеть (MLP) в каждом слое для точного прогнозирования выходных данных.

Она способна справляться с большими вариациями данных и комбинирует преимущества высокой точности и вычислительной эффективности.
