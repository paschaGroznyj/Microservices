Ассистент
12 инструментов
💡
Ассистент понимает свободный текст — просто опишите задачу своими словами, он сам выберет нужный инструмент.
search_db
Поиск по базе документов
Семантический поиск по загруженным файлам и статьям. Пример: «найди документы про conformance checking»
summarize_file
Суммаризация файла
Краткое резюме или ревью конкретного файла из базы.
summarize_new
Обзор новых статей
Суммаризация статей которые появились недавно — удобно для ежедневного мониторинга.
summarize_all
Ревью всех файлов
Сводный обзор по всему содержимому базы знаний.
analyze_folder
Анализ папки
Структурный анализ содержимого выбранной папки — темы, количество, распределение.
summarize_filt
Дайджест с фильтром
Суммаризация с условием по дате или теме. Есть встроенная отправка результата на почту.
send_digest_email
Дайджест на email
Формирует сводку по всем файлам и отправляет на указанный адрес.
summarize_basket
Ревью избранного
Создаёт ревью или саммари по статьям добавленным в корзину избранного ★
digest_basket
Дайджест избранного
Сводка по всем статьям из корзины — темы, выводы, связи между публикациями.
rebuild_categories
Переопределить категории
Переназначает категории в метаданных документов на основе содержимого.
delete_file
Удалить файл
Удаляет документ из базы знаний по названию или идентификатору.
general_question
Общие вопросы
Произвольный вопрос ассистенту без привязки к конкретному инструменту.
📄
Поиск статей
arXiv
🔍
На другом конце поисковой строки работает LLM — пишите запрос на русском, она сама извлечёт ключевые слова и категории arXiv.
быстрый поиск
Кнопки быстрого поиска
Готовые запросы под строкой ввода — нажмите чтобы запустить поиск по популярным темам без ввода текста.
поисковая строка
Произвольный запрос
Напишите тему в свободной форме — например «свежие статьи по object detection». LLM преобразует запрос в поисковые термины.
★ избранное
Добавить в корзину
Нажмите на звёздочку на карточке — статья добавляется в корзину избранного. Звёздочка станет жёлтой, счётчик увеличится.
корзина
Раздел избранного
Кнопка «Избранное» в панели поиска открывает список сохранённых статей. Из корзины можно передать статьи ассистенту для анализа.
flip-карточка
Переворот карточки
Кликните по карточке — она перевернётся и покажет аннотацию статьи. Нажмите крестик или фон чтобы закрыть.
перевод
Перевод аннотации
На обратной стороне карточки есть кнопка «Перевести» — LLM переводит аннотацию на русский и сохраняет результат.
