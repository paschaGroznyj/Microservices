### Цель разработки инструмента

Автоматизация процесса сбора, фильтрации и агрегации актуальных информационных материалов из открытых интернет-источников с последующим формированием дайджестов по запросам пользователей.

### Пользователи инструмента

Целевая аудитория:

участники ЦК по Process Mining, ответственные за сбор, анализ и публикацию материалов, связанных с методологией, инструментами и опытом применения методологии Process Mining в различных сферах деятельности.

### Основные функции инструмента

1. Сбор и обработка информации

а) **Автоматический сбор информации**: инструмент раз в 2 недели запрашивает данные (материалы статей, исследований и пр.) от источника (интернет ресурс, на котором размещены материалы исследований, практический опыт применения методологии и инструментов PM), используя настроенные фильтры (ключевые слова, категории), сохраняет данные в Базу знаний (БЗ), формирует обзор добавляемого материала и размещает в БЗ.

Источники:
- https://arxiv.org
- https://ieeexplore.ieee.org
- https://scholar.google.com
- https://fluxicon.com

Парсеры находятся в папке - [pm_parser](app/agent_pm/pm_parser/pipeline_parsers.py)

б) **Обработка данных источника**: инструмент, по ключевым словам, находит информацию в источнике, формирует дайджест по источнику, определяет категорию источника и размещает материал в Базе знаний на cloud.ru

2. Формирование дайджеста в заданном формате - [работа агента](app/agent_pm/agent.py)

ДОСТУПНЫЕ ИНСТРУМЕНТЫ АГЕНТА:

    1. [search_db] - найти документы по запросу  

    2. [summarize_file] - суммаризация/дайджест файла

    3. [summarize_all] - дайджест ВСЕХ файлов
    
    4. [rebuild_all] - ПОЛНАЯ перестройка БД
    
    5. [summarize_filt] - суммаризация/дайджест с условием по дате или теме

а) [Дайджест](app/agent_pm/summary.py) по всем материалам Базы знаний (БЗ): инструмент формирует обзор всех материалов, содержащихся в БЗ по запросу пользователя.

б) [Дайджест](app/agent_pm/summary_period.py) по тематическим материалам БЗ: инструмент формирует обзор всех материалов, относящихся к заданной пользователем тематике.

в) [Дайджест](app/agent_pm/summary_period.py) по материалам БЗ за период: инструмент формирует обзор всех материалов, добавленных в БЗ за заданный пользователем период.

г) Формирование [дайджеста](app/agent_pm/summary_period.py) по нескольким статьям по категории.

д) Возможность создать [векторную базу](app/agent_pm/vector_db.py) данных для поиска релевантных документов.

е) [Поиск](app/agent_pm/update_md.py) релевантных документов по текстовому запросу.

3. **Формирование обзора в заданном формате**

Обзор материала БЗ в следующем формате:

### Формат дайджеста

Дайджест метриалов внешних источников за период с xx.xx.xxxx по xx.xx.xxxx

[Название статьи1]
- Ссылка на источник
- Саммари статьи 1

[Название статьи2]
- Ссылка на источник
- Саммари статьи 2

### Формат обзора

- Заголовок на русском языке
- Название статьи
- Авторы
- Ссылка на источник

- Описание
  1. Цель
  2. Проблема
  3. Задачи
  4. Подход
  5. Как реализуется подход
  6. Оценка результатов
  7. Вывод


4. Дополнительный функционал

- возможность выбирать временный период для формирования дайджеста по запросу
- возможность выбирать ключевые слова или темы для формирования дайджеста
- сохранение в облако [УВА - Cloud.ru](app/agent_pm/pm_parser/botocore_client.py)

Дайджесты формируются при помощи агента, который работает с LLM - GigaChat или Qwen3-VL-8B-Instruct, нужны токены для активации моделей через Huggingface или GigaChat, вызываются они при помощи файла [config.py](app/core/config.py), а токены располагаются в файле [.env](../env.example).

Дайджесты сохраняются в объектное хранилище Cloud.ru - поэтому нужно также получить k[OBS_ACCESS_KEY, OBS_ACCESS_SECRET](../env.example). 

Инструкция по получению доступа к [Облаку УВА](https://uva-advanced.s3-website.cloud.ru/).
