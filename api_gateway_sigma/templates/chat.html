Что такое CatchPM

                        

                            CatchPM — агентная система, работающая поверх базы данных PostgreSQL с векторным расширением pgvector. Агент понимает естественный язык, самостоятельно выбирает инструменты и выполняет многошаговые задачи: от поиска по смыслу запроса до формирования структурированных отчётов.
                        

                        

                            Система ориентирована на центр компетенций Process Mining: автоматически отслеживает новые публикации, оценивает их релевантность, генерирует ревью и собирает тематические дайджесты для рассылки команде.
                        

                        

                            
«Аналог LLM Wiki по Карпати — живая база знаний на SQL, которая растёт и синтезирует информацию по мере работы с ней.»

                        

                    


                    

                        
Ключевые возможности


                        
Работа с базой данных

                        
Агент напрямую обращается к PostgreSQL: выполняет SELECT/INSERT/UPDATE, строит аналитику по корпусу статей, отслеживает историю изменений через audit-лог. Векторный поиск pgvector обеспечивает семантический поиск по всему корпусу знаний.


                        
Автоматизация парсеров

                        
По запросу на естественном языке система собирает и запускает парсер нужного источника: научные архивы, новостные ленты, корпоративные порталы. Готовые скрипты сохраняются в библиотеку кода и переиспользуются без повторной генерации.


                        
Генерация документов

                        
Из песочницы — Excel, PDF, PPTX, PNG-дашборды, HTML-страницы. Всё создаётся программно на Python, без сторонних SaaS. Результат — готовый файл, который сразу отправляется пользователю.
